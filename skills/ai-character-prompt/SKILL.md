# AI 角色参考提示词

这是本图库的辅助 Skill。先确定产物是插画简报还是 H3 Ref2VA 提示词；不要因角色名就自行切换模式。

## 读取与绑定

读取选中的实际图片和对应角色资料。区分图片可见外观、带来源的社区描述、本项目二创建议。视觉身份以图片为准；没有看过图时说明限制，不编造瞳色、发饰、服装或尾部特征。

确定标准版、中间体型版或 Q 版。一次参考同一角色的一种体型，除非用户明确要求变体转换。体型不是年龄。多视图设定表表达同一角色，生成画面是否保留排版由用户的创作目标决定。

在提示词前列出绑定表：实际文件、输入顺序、引用标签、用途、保留项与允许变化项。H3 标签来自真正输入顺序：第一张图片对应 `<Picture 1>`；没有上传的视频或音频不得编造标签。顺序更改后更新所有引用。

## 创作简报

从用户要求确定动作、地点、画幅、时长、镜头数、对白和音乐；缺少非关键细节时采用简单、易检查的方案并标为假设。角色性格通过可见行为表达，勿以背景介绍代替画面描述。

插画任务输出“身份保留项 + 本次变化 + 场景与构图 + 完成检查项”，不套用视频字段。

## H3 Ref2VA

用 [references/exhibition-ref2va.md](references/exhibition-ref2va.md) 了解本项目单角色示例，再按实际素材重写。六个字段必须依次为：

```text
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

使用英文描述与稳定的参考标签；对白保留用户原语言。每个镜头交代构图、角色位置、动作过程、环境、镜头运动和声音。首镜写 `[Shot 1]`，后续镜头才标出实际切换时间。单镜头不因时间推进而拆成多个 Shot。台词使用稳定说话者 `(S1)` 和 `<d>[Chinese] 台词</d>`；未要求对白时不主动添加。

只把图片用作身份参考时，在 `<Subject 1>` 定义中引用 `<Picture 1>`，不把设定表声明成第一帧。若需要首帧严格对齐，应明确切换为 I2VA 并阅读官方基础模式规范，不复用这份 Ref2VA 示例。

输出前检查：所有标签有实际素材，保留和改动不矛盾，体型没有漂移，动作能在目标时长内完成，台词长度合理，音频引用确实存在，角色资料的证据层级没有被改写。

## 交付

交付绑定表、提示词和简短中文检查说明。把未观察到的外观、未确认的参数和创作假设单列。说明这是文本草稿，效果须实际生成后检查。默认止于文本交付，不提交 ComfyUI 队列、不上传素材、不安装插件或技能。

复杂音频复用、长视频续写或模式转换时，读取 [官方 h3-prompt-writing](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/.agents/skills/h3-prompt-writing) 及对应 reference。官方规范无法取得时，保留当前有限支持范围，不宣称完整支持。
