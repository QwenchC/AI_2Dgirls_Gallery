# 离线图鉴使用指南

AI MUSE 为 AI 拟人角色创作提供形象参考、资料索引与创作简报。下载完整仓库后，用现代浏览器打开根目录的 `index.html`；Windows 也可双击 `打开展览.cmd`。浏览图鉴无需安装依赖或登录账号。

## 浏览角色

在“角色图鉴”中选择标准版、中间体型版或 Q 版。搜索框支持角色名称、别名、配色和风格关键词；在非输入状态按 `/` 可快速定位搜索框。

点击角色卡可阅读三个页签：

- **角色档案**：社区资料、当前图像的视觉特征与本项目二创设定。
- **创作提示**：角色辨识点、场景灵感和多视图参考的使用方法。
- **来源与说明**：作品链接、作者、证据范围和待考证内容。

资料卡内可以再次切换体型、查看或下载原始设定图。页签支持左右方向键切换，按 Escape 可关闭资料卡。

三种体型表示造型比例，不是年龄设定。设定板中的多个视角属于同一角色；创作时应明确需要的是单幅画面、角色设定表还是活动镜头。

## 编写创作简报

点击“用这个角色创作”，将当前角色和体型带入创作工坊。填写场景、动作与情绪，选择镜头，再点击“生成创作简报”。正文可以继续手动编辑、复制或下载为 TXT。

更改左侧选项不会立即覆盖已有正文。状态提示会说明当前简报对应的角色与体型，以及是否需要重新生成。下载文件名跟随当前正文对应的版本；手动编辑的正文使用通用文件名。

简报生成器在浏览器内拼接文本，不分析图片或调用模型。它适合作为插画策划或视频提示词的起点。H3 视频创作可继续阅读[创作指南](creation-guide.md)、[工作流参考](h3-workflow.md)和[提示词 Skill 指南](prompt-skill-guide.md)。

## 离线阅读与分享

图像、资料摘要和创作指南都随仓库保存。外部作品与工具链接需要联网访问。移动或分享图鉴时保留完整目录，以确保页面、图像与资料之间的相对链接有效。

浏览器若限制剪贴板操作，可选中文本后手动复制，或直接下载 TXT。若直接打开 HTML 遇到浏览器限制，也可使用常规静态文件服务器浏览。

角色资料中的“社区资料”和“本项目二创设定”用途不同。分享作品时保留适用的来源与贡献署名，并核对所用素材的授权条件。补充设定、来源或贡献者名字，可通过仓库 Issue 联系维护者。
