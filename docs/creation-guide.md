# 从角色图到 AIGC 作品

本指南面向想用本仓库角色创作插画、短片和展览物料的爱好者。展览页面、创作简报和辅助 Skill 可离线阅读；视频生成需要另行准备兼容的生成工具。教程描述的是通用创作流程，不构成生成效果保证。

## 1. 先选一种体型，再选一个动作

每个角色有标准版、中间体型版和 Q 版。它们是同一角色的视觉变体，不代表三个角色，也不代表年龄设定。一次测试先选一种体型；需要形态转换时，明确说明各参考图的职责与变化过程。

把需求拆成四行，通常比堆砌形容词更容易检查：

```text
角色与体型：DeepSeek / Q 版
参考用途：人物身份、配色、服装和比例，不复制设定表排版
本次动作：看向镜头、眨眼、轻轻挥手
成片要求：约 5 秒、单镜头、二次元风格、无对白、无背景音乐
```

多视图、文字标签和色块属于设计资料。可以直接使用设定板，但要说明不同视角表达同一角色；如果生成结果出现重复人物或拼版，可另存单视角参考副本，保留关键配饰和体型，不覆盖原始素材。

外观以实际选中的图片为准。资料卡中标为“本项目二创建议”的性格、职业和背景是创作提案，不是官方设定或全社区共识。

## 2. 选择适合的 H3 模式

| 创作目的 | 模式 | 提示词依据 |
| --- | --- | --- |
| 用角色参考图创作新场景、新动作 | Ref2VA | 六段式参考生成规范 |
| 让一张开场画面开始活动 | I2VA | 基础模式规范与首帧对齐说明 |
| 连接指定的开场与结束画面 | FL2VA | 基础模式规范与首尾帧对齐说明 |
| 从文字构建完整场景 | T2VA | 基础模式规范 |

角色多视图设定板通常适合提供身份参考。如果要求它成为视频第一帧，模型可能保留拼版布局；需要单角色开场时，先准备对应的场景图。模式定义与格式见 [MiniMax 官方提示词 Skill](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/.agents/skills/h3-prompt-writing)。

## 3. 参考生成的通用步骤

1. 选择角色图与体型，列出身份保留项和本次允许的变化。
2. 在兼容的 ComfyUI 工作流中绑定素材，检查实际输入顺序。不要从文件名猜参考编号。
3. 用创作简报或辅助 Skill 整理提示词。为每张图、每段视频和音频说明用途，避免互相矛盾。
4. 按所选模型、工作流及硬件条件设置画幅、时长和采样参数。参数输入若已连线，应检查上游实际控制值。
5. 由创作者提交生成，检查完整结果，再决定下一步修改。
6. 保存实际使用的参考、提示词、工具版本、参数和后期说明，便于复现与署名。

完整的通用链路、素材绑定和验收要点见 [H3 工作流参考](h3-workflow.md)。公开模型与工具资源可从 [MiniMax H3 官方项目](https://github.com/MiniMax-AI/MiniMax-H3)、[Comfy-Org 模型页面](https://huggingface.co/Comfy-Org/MiniMax-H3) 和 [时间线导演台](https://github.com/Songssx/ComfyUI-MiniMaxH3-TimelineDirector) 查阅；版本和兼容要求以各项目说明为准。

## 4. 提示词 Skill 怎么用

官方 `h3-prompt-writing` 指导智能体将创作要求整理成对应模式的提示词。仓库内的 [ai-character-prompt](../skills/ai-character-prompt/SKILL.md) 是本项目的补充工具，帮助读取角色资料、保持选定体型、建立参考绑定表并输出可检查的草稿；它不是官方 Skill 的转载，也不会执行生成。

可以将实际图片与以下需求一起交给支持读取素材的智能体：

```text
请使用本仓库 skills/ai-character-prompt/SKILL.md。
使用 DeepSeek 的 Q 版图片作为唯一图片参考，保持这一版比例。
创作约 5 秒的展览欢迎短片：单镜头，看向镜头、眨眼、轻轻挥手。
没有对白，没有 BGM；只保留衣料轻响和安静室内环境声。
先列出实际参考绑定表，再输出英文 Ref2VA 提示词和中文检查说明。
```

展览中的生成器只拼接创作简报，不分析图片或调用语言模型。详细规范和可离线阅读的完整示例见 [提示词 Skill 指南](prompt-skill-guide.md)。

## 5. 检查结果与分享作品

| 现象 | 优先检查 |
| --- | --- |
| 人物外观混合 | 是否混入其他角色、体型或错误参考编号 |
| 设定板变成多人 | 是否说明各视角属于同一身份，是否需要单视角副本 |
| 改了参数却没变化 | 实际控制值是否来自上游连线 |
| 无对白却出现说话 | 是否残留示例台词或错误音频引用 |
| 续写处突然换脸、换装 | 重叠参考、动作结束状态及下一段开场描述是否一致 |
| 动作未完成 | 剧情是否过密，是否写出可见的动作先后过程 |

发布作品时标注实际参考与贡献关系，不把素材提供者自动认定为角色首创者。参考资料的致谢、补充署名与侵删事宜见仓库 README。
