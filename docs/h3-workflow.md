# MiniMax H3 通用工作流参考

本文件依据公开上游资料介绍常见工作方式。不同版本的节点、模型和界面可能变化；实际操作前应阅读对应版本的上游文档。

## 参考图生成视频

Ref2VA 适合将角色身份、场景、动作或声音作为参考，再生成新的镜头。一个概念性的 ComfyUI 链路为：

```text
实际参考素材 + 提示词 + 生成尺寸与时长
                    ↓
          H3 参考编码与条件准备
                    ↓
              音视频联合采样
                    ↓
          视频解码 + 音频解码
                    ↓
              合成与保存视频
```

模型、文本编码器、视频与音频 VAE 应匹配所选工作流。请从 [MiniMax H3 官方项目](https://github.com/MiniMax-AI/MiniMax-H3) 和 [Comfy-Org 模型资源](https://huggingface.co/Comfy-Org/MiniMax-H3) 核对支持范围、下载方式及使用条款。不要把工作流中的示例输入值视作所有设备的推荐配置。

## 素材绑定

| 素材 | 常见职责 | 写提示词前确认 |
| --- | --- | --- |
| 角色图 | 身份、服装、配色、体型 | 哪些特征必须保留，是否有多视图 |
| 场景图 | 空间布局、光照、背景风格 | 是环境参考还是具体画面锚点 |
| 视频 | 动作、运镜、剪辑结构、续写起点 | 参考、编辑和续写属于不同关系 |
| 音频 | 音色、节奏、环境声或实际复用 | 是否真的传入，复制声音还是只参考特点 |

提示词标签必须对应实际素材顺序。没有音频输入时，不要因视频文件“可能有声音”就虚构音频标签。只有身份参考时，不应自动把角色设定板声明成视频第一帧。具体标签与保留关系见 [官方 Ref2VA 规范](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/.agents/skills/h3-prompt-writing/references/ref-en.txt)。

## 参数检查

- **模式**：确认使用参考生成、首帧、首尾帧或文生视频，按模式选择提示词格式。
- **画幅与尺寸**：根据输出用途与工作流支持范围选择；已连线的字段可能由上游控制。
- **时长与帧率**：检查所选模型的支持范围及工作流的帧数对齐规则，剪辑时以实际输出为准。
- **采样与加速组件**：遵循对应权重和组件文档，不因名称或示例自动推断采样步数。
- **复现记录**：记录实际种子、参数、模型版本和参考顺序；这些信息由创作者保存到自己的作品记录中。

## 时间线参考与分段创作

[Songssx 时间线导演台](https://github.com/Songssx/ComfyUI-MiniMaxH3-TimelineDirector) 提供可视化素材规划。使用时读取界面给出的实际参考编号；节点名称、功能与兼容要求以上游当前版本为准。

分段续写时，先检查上一段结束画面的身份、动作阶段、机位和声音，再描述下一段的衔接。采用固定重叠区时，合并前确认实际重叠帧数，避免重复动作与对白。人物替换与固定画面有不同目的，应根据任务选择对应参考方式。

## 生成后的验收

先看完整片段，再逐项检查身份、服装、体型、肢体、动作连续、镜头空间、音画同步和字幕。存在明显错误时，不把该片段直接作为后续片段的身份依据。一次改变一个主要因素通常更容易定位问题。

本仓库提供文本策划与参考资料，不包含模型、生成服务或效果承诺。相关工具、模型和素材各自的使用条款仍需分别核对。
